# Leaderboard Seasons Architecture

WordPot operates on a 30-day seasonal competitive cycle.

## Seasonal Scoring Rules
- **Base Points**: Points earned per valid word submitted in arenas.
- **Booster Multipliers**: 2x point multiplier applied when booster games remain on user account.
- **Season Rewards**: Top 50 players on the seasonal leaderboard earn CELO token reward pools at season conclusion.
